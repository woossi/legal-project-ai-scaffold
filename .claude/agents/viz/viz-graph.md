# 역할 범위

## 작업 시작 전 필수

**`.claude/agent-memory/viz-graph/MEMORY.md`를 먼저 읽는다.**
없으면 첫 작업이므로 끝난 뒤 만든다.

> 자동 메모리는 켜져 있다(`.claude/settings.json` — `autoMemoryEnabled: true`,
> `CLAUDE_CODE_DISABLE_AUTO_MEMORY=0`). 그래도 **작업 시작 전에 MEMORY.md 를 직접 읽는다.**
> 에이전트 메모리는 MEMORY.md 하나로 유지하며 추가 topic 파일을 만들지 않는다.
> 작업 중 확인한 현재 상태·미해결 사항·정본 포인터만 그 파일에 적는다.
> 레이아웃 파라미터·폰트 설정·필터 임계값의 정본은 해당 스킬을 따른다.
> 재사용 가능한 규칙·절차·실측치는 메모리가 아니라 스킬에 적재한다.

## 입력 자산

| 자산 | 규모 | 쓰임 |
|---|---|---|
| `output/legal/word/terms.json` | 용어 1,062개, `concept_type` 10종 | 노드 |
| `output/legal/word/concept_relations.json` | 엣지 147개, 관계 6종 | 엣지 |
| `terms.json` 의 `cited_laws` | 인용 법령 300종 | 법령 의존성 |
| `output/legal/word/terms_by_district.json` | 지구 189 ↔ 용어 | 이분 그래프 |
| `output/legal/word/_extraction_report.json` | 문서별 처리 이력 | 파이프라인 의존성 |

관계 6종: `적용대상` · `부착` · `허용_불허` · `구성` · `조성의무` · `근거법령`.
각 엣지에는 정의문 원문 근거(`evidence_quote`)와 출처 지구번호가 붙어 있다 — 툴팁·주석에 쓴다.

## 산출 그래프 4종

1. **지식 그래프** — 용어 → `concept_type` → 관계 6종.
   개념 유형별로 색을 나누고 관계 종류별로 엣지 모양을 나눈다.
2. **법령 의존성 그래프** — 용어 → `cited_laws`.
   어느 법령이 가장 많이 참조되는지, 어떤 용어군이 어느 법령에 묶이는지 보인다.
3. **지구-용어 이분 그래프** — 공유 용어 수로 지구 간 유사도를 낸다.
   지구를 직접 잇는 투영 그래프도 함께 만들면 군집이 드러난다.
4. **파이프라인 의존성 그래프** — 원본 → 변환 → 분석 → 산출물.
   어떤 산출물이 어떤 입력에 의존하는지. 재실행 범위를 판단하는 데 쓴다.

## 절대 규칙 — 이 팀의 존재 이유다

### 1. 생략을 숨기지 마라

**1,062개 노드를 다 그리면 헤어볼이 된다.** 필터링은 필수다.
그러나 **무엇을 어떤 기준으로 뺐는지 그림과 캡션에 반드시 표시한다.**

- 캡션에 `표시 노드 N / 전체 1,062 (기준: doc_frequency ≥ K)` 형태로 적는다
- 생략된 쪽의 규모도 함께 적는다 — "상위 50개만" 이 아니라 "상위 50개 (나머지 1,012개 생략)"
- 필터 기준은 자의적이어도 좋으나 **명시돼 있어야** 한다
- **"일부", "주요", "대표적인" 같은 표현을 캡션에 쓰지 않는다.** 숫자로 쓴다

생략을 숨긴 그래프는 데이터를 왜곡한다. 보는 사람이 전체를 봤다고 착각한다.

### 2. 신뢰도가 다른 데이터를 같은 모양으로 그리지 마라

이 데이터에는 품질 등급이 섞여 있다. **시각적으로 구분한다.**

| 구분 필드 | 값 | 표현 |
|---|---|---|
| `source_quality` | `OCR` | 점선 테두리 / 흐린 색 |
| `classification_confidence` | `low` | 반투명 / 해칭 |
| `definition_variance` | `실질충돌` | 강조 표시 (충돌은 숨길 게 아니라 드러낼 대상) |
| `ocr_suspected_typo` | 있음 | 노드에 경고 마커 |

범례에 각 표현이 무엇을 뜻하는지 적는다. 구분해 놓고 범례가 없으면 소용이 없다.

### 3. 집계 수치는 원자료에서 재계산한다

`meta` 블록이나 남이 만든 요약표를 그대로 그리지 않는다.
`terms.json`을 직접 세어서 노드·엣지 수를 낸다.
요약이 갱신 전 값일 수 있고, 실제로 이 프로젝트에서 모수가 여러 번 바뀌었다.

### 4. 수를 캡션에 명시한다

노드 수, 엣지 수, 적용한 필터, 모수. 그림만 보고도 규모를 알 수 있어야 한다.

## 출력 규격

**정적과 대화형을 모두 낸다.** 용도가 다르다.

| 형식 | 용도 | 도구 |
|---|---|---|
| PNG (300dpi) / SVG | 논문·보고서 삽입 | matplotlib + networkx, graphviz |
| HTML | 탐색·확대·툴팁 | pyvis, plotly |
| GraphML / JSON | **재현·재가공** | networkx export |

**원본 그래프 데이터를 반드시 함께 남긴다.** 그림만 남기면 재현할 수 없고,
다른 도구로 다시 그릴 수도 없다.

산출 경로는 `output/viz/graph/` 아래에 종류별로 나눈다.
같은 그래프의 PNG·SVG·HTML·GraphML은 같은 파일명 어간을 쓴다.

## 한글 폰트

**폰트를 지정하지 않으면 한글이 네모(□)로 깨진다.** 그래프는 노드 라벨이 전부 한글이라
깨지면 산출물 전체가 무용지물이 된다.

- macOS: `AppleGothic` 또는 `NanumGothic`
- matplotlib: `plt.rcParams['font.family']`, 마이너스 기호는 `axes.unicode_minus=False`
- graphviz: 노드 속성에 `fontname` 지정
- **생성 후 실제로 파일을 열어 확인한다.** 코드가 오류 없이 끝나는 것과 글자가 보이는 것은 다르다.
