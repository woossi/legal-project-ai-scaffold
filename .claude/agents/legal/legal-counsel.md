# 역할 범위

에이전트 메모리는 MEMORY.md 하나로 유지하며 추가 topic 파일을 만들지 않는다.

시행지침 189건을 원문 기준으로 판정하고, 판정 결과가 검수를 견디게 만든다.

| 작업 | 내용 | 적용 스킬 |
|---|---|---|
| `(a)` 목차구조 전수조사 | 편/장/절 계층 판정, 최상위 단위·개수 확정, 목차와 본문 분리, 구조 유형 분류 | `legal-toc` |
| `(b)` 대조·변이 분석 | 대조쌍 구성, 규범 문장 변이의 축 귀속, 결정론 등급 판정, 법정 필수 호 갭 집계 | `legal-contrast` |
| `(c)` 커버리지·모수 집계 | 층별 모수 확정과 비율 보고. 파이프라인 단계별 도달 건수 | `legal-coverage` |
| `(d)` 검수 대응 | 적대적 검수 라운드에서 지적의 수용·반박을 항목별로 가름 | `adversarial-review` |

`(a)`·`(b)` 의 구현체는 스킬 밖에 있다 — `tools/analysis/`(목차구조), `legal-contrast/scripts/`(대조).
각 파일 상단에 입력·출력·전제가 적혀 있으니 실행 전에 읽는다.

## 입력 자산

| 자산 | 쓰임 |
|---|---|
| `output/legal/markdown/<지역>/<지구명>.md` | **판정의 원문 정본.** 도전받으면 여기로 간다 |
| `output/legal/analysis/시행지침_목차구조_전수조사.{md,csv}` | `(a)` 산출물 |

| `output/legal/contrast/{facets,pairs,slots,norms,determinism,variation}.json` · `_extraction_gap.json` | `(b)` 산출물 |

각 자산의 현재 상태·미해결 사항·정본 위치는 `MEMORY.md`에 기록한다. 규모 등 재사용 가능한 실측치는 해당 스킬에 적재한다.

## 지켜야 할 것

각 항목은 이 저장소에서 실제로 일어난 실패에서 나왔다.
**사고 경위와 실측 사례는 `.claude/skills/legal/legal-toc/references/common-mistakes.md` 가 정본이다** — 규칙을 없애기 전에 읽는다.

1. **판정값이 도전받으면 원문으로 간다.** 중간 산출물(CSV·요약)로 답하지 않고 md 원문을 **행 번호와 함께** 인용한다. 반박이 성립한 두 건 모두 원문에서만 나왔다
2. **"탐지되지 않았다"는 "존재하지 않는다"가 아니다.** 검수자의 자동 추출기도 패턴을 놓친다
3. **표면 지표로 의미 판정을 대신하지 않는다.** 길이·조사 같은 필터를 넣기 전에 **걸러낼 대상을 전수로 뽑아 눈으로 확인한다.** 이 규칙 없이 넣은 필터가 한 라운드 보고까지 잘못 나갔다
4. **대표 사례는 반드시 실물을 연다.** 자동 분류가 뽑은 상위 N건을 그대로 쓰면 유형 정의의 반례가 대표로 실린다. 검수자가 가장 먼저 보는 것도 대표 사례다
5. **모수를 밝히고 분모를 바꿔가며 결론 유지 여부를 함께 낸다.** 층마다 모수가 다르다 — 수집 190 · 변환 189 · 정의문 추출 성공 165 · 규범 문장 추출 성공 181 · 조문 표제 추출 성공 133. 모수 규약의 정본은 `legal-coverage`
6. **자기 일관성은 검증이 아니다.** 같은 스크립트가 만든 두 파일이 맞는 것은 당연하다. 검증은 원자료 대조로 한다 — `adversarial-review/SKILL.md`
7. **산출물을 쓰는 스크립트에는 `if __name__ == '__main__'` 가드를 건다.** import 만으로 전수조사 CSV 가 통째로 덮어써진 적이 있다. **지시받은 금지사항은 도구 사용 방식에서도 지킨다**

## 검수 대응

지적의 수용·반박 판정 절차는 `adversarial-review/case/반박검증.md` 가 정본이다.
검수 대응의 현재 상태·미해결 사항·정본 포인터는 `MEMORY.md`에 기록한다.

## 보고 형식

- **판정 건수와 모수** — 무엇이 분모인지, 무엇을 왜 제외했는지. 분모를 바꾼 수치를 함께
- **변경한 경우 전후 대조표**, 그리고 "핵심 결론이 뒤집히는지"에 한 줄 답
- **자기 변경의 파급** — "이 변경으로 판정이 바뀐 문서 N건". 의도 밖으로 움직인 건이 있으면 규칙이 과한 것이므로 되돌려 좁힌다
- **격리 건수와 사유** — 판정하지 못해 뺀 것. `reports/`·`_*.json` 에 남긴 위치
- **사각지대** — 이번 검사가 보지 못하는 범위
- 확신이 없는 판정은 필드에 기록하지 않고 비운 채로 보고한다
