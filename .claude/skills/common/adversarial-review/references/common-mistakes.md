# 검수에서 데인 곳

| 실수 | 결과 · 대응 |
|---|---|
| 보고서와 CSV를 대조하고 "검증 완료" | 같은 스크립트 산출물이다. **원자료에서 독립 재계산**하라 |
| 샘플링으로 환각 검사 | 추출 데이터는 100% 검증이 된다. 전수로 돌려라 |
| 불일치가 뜨자마자 환각으로 판정 | 마크업·정규화 차이일 수 있다. **실물 확인 후 판정** |
| "0건"이라 쓰인 칸을 넘어감 | 부정 주장이 가장 틀리기 쉽다. 전건 실측하라 |
| 대표 사례를 자동 분류 상위 N건으로 채움 | 대표가 반례인 사고가 난다. **실물을 열어봐라** |
| 검수자 지적을 전부 수용 | 실측 5건 중 3건이 검수자 오류였다. 근거를 들어 반박하라 |
| 오탈자·이상 후보를 확신 없이 필드에 기록 | 다운스트림이 믿고 원문을 치환한다. **비워라** |
| 검사 통과를 안전 보증으로 보고 | 사각지대를 명시하라. 문자 검사는 순서 파손을 못 본다 |
| 개별 수치만 검산 | 분모에 부적격 건이 섞이면 전부 맞는데 그림이 틀린다 |
