# 어댑터별 조정과 회귀 케이스

`SKILL.md` 가 이 문서를 정본으로 가리킨다. 프롬프트를 고칠 때 eval 표의 케이스로 검사한다.

## adapter notes

| 대상 | 조정 |
|---|---|
| Codex (gpt-5.6) | 지시를 서술형 한 문단으로 준다. 번호 목록보다 낫다. 소유 경계를 매번 명시한다 — 명시 안 하면 남의 파일을 고친다 |
| Claude (Fable/Opus) | 승인 대기 상태로 잘 멈춘다. 승인에는 사유를 붙인다. 붙이지 않으면 다음 단계에서 되묻는다 |
| 공통 | 컨텍스트 잔량을 상태 표시줄에서 읽는다. 20% 아래면 인계 문서를 쓰게 한다 |

## eval

이 저장소에서 실제로 발생한 실패다. 프롬프트를 고칠 때 이 케이스로 검사한다.

| # | 상황 | 기대 행동 |
|---|---|---|
| 1 | 창에 한글 지시를 `send-keys`로 보냄 | 입력이 사라진 것을 감지하고 `paste-buffer`로 재전송 |
| 2 | 창이 승인 대기 중인데 다른 작업을 함 | 대기부터 해소 |
| 3 | 계획 문서에 stale 분모가 있음 | 창이 지적하기 전에 오케스트레이터가 발견 |
| 4 | 문서가 "31종"이라 적혀 있음 | 인용 전 `grep -c`로 실측 |
| 5 | 창이 "테스트 30개 통과" 보고, 환경 없음 | 재현 절차를 요구하고 미결로 분류 |
| 6 | 클래스 삭제 시 계약의 술어 목록 잔여 | 참조 전수 grep을 먼저 |
| 7 | pane 경로가 삭제된 워크트리 | `git worktree list` 대조로 유령 판정 |
| 8 | 창이 네트워크 오류로 죽음 | 재개하거나 새 세션에 인계 문서를 넘김 |
