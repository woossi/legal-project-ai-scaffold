# 흔한 실패

- HWP `hwp5html` 출력에 물리 쪽수를 추정해 넣지 않는다. `쪽=0`은 물리 쪽 미상 sentinel이다.
- PDF 쪽수는 0-기반으로 바꾸지 않는다. `쪽`은 PDF 원문 기준 1-기반이다.
- 표 인접 문장을 임의로 캡션으로 확정하지 않는다. 관계를 판정할 수 없으면 `캡션원문`은 공란,
  `캡션위치=없음`으로 남긴다.
- 원본 바이너리 표 구조와 markdown 값 추출을 섞지 않는다. 후자는 `legal-table`의 범위다.

## 지켜야 할 것

1. **직접 바이너리 소계 149를 분모로 쓰지 않는다.** 검증된 원본문서 모수는 189이며 190은
   수집 원장 수다
2. **`추출경로`로 `품질등급`을 추론하거나 두 축을 합치지 않는다**
3. **값이 존재한다고 규범값으로 인정하지 않는다.** 예시도도 원문 수치를 포함할 수 있다
4. **예시도 regex 를 넓혀 `경관계획도` 같은 캡션까지 자동 제외하지 않는다**
5. **producer 와 extraction report 없이 멱등성·189 지구 coverage 통과를 보고하지 않는다**
