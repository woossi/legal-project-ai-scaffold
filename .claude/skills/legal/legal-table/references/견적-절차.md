# 재변환 견적과 주어 미상 견적

견적서이지 판단서가 아니다. `SKILL.md` 의 실행 절에서 이 문서를 가리킨다.

## 통합 재변환 견적 — 견적서이지 판단서가 아니다

`_retransform_estimate.{json,md}` 는 조문 무결성(codex)과 표 손실(이쪽)을 join 한다.
**재변환 실행 여부는 사용자가 정한다.** 이 산출물은 이득과 대가를 나란히 놓는 데서
멈추고 권고하지 않는다 — 게이트 E5 가 권고 어휘를 검사한다.

### join 키 함정

codex `documents[].lc5` 는 **이름과 달리 14자리 지구번호**다(`41820DA2016001`).
이쪽 `dstrcAppnNo` 와 189/189 매칭한다. **이쪽 `lc5`(5자리 법정동코드 `41590`)와
붙이면 전건 불일치가 난다.** 이름이 같은데 값 도메인이 다른 필드를 나란히 비교하지
않는다(`프로젝트-설계구조.md` §3).

### 대가는 층에 비례하지 않는다

대가 4항의 정본은 codex 견적서 `output/legal/analysis/시행지침_무결성_재변환_견적.md`
§재변환 연쇄비용이며 그대로 인용한다. **1~3항은 재변환 문서 수와 무관하게 한 번
발생한다** — corpus 는 전건 glob 으로 줄범위·SHA 를 다시 만들고, `legal-statute` 검증 게이트 12와
downstream 10개 파일(xref 3 · contrast 7) 생성기에도 증분 경로가 없다. 4항도 스캔은
전건이며 문서 수에 비례하는 것은 복원 확인 몫뿐이다. 부분 재변환이 대가를 비례해
줄이지 않는다는 뜻이며, 이 사실을 층별 표와 함께 낸다.

### 45 는 대입하지 않는다

"재변환하면 대조 가능 지구가 45에서 몇으로 느는가" 는 **답하지 않는다.** 45 의 모수
정의가 이 저장소 산출물에서 재현되지 않기 때문이다(조례 쪽 관할은 27개). 모수를
모르는 채로 증가분을 내면 숫자를 발명하는 것이다. 대신 회수 가능 지구를 이쪽 모수로
정확히 세고, 45 와의 연결은 "모수 정의가 확인되면 대입한다" 로 남긴다. 이 미확정은
`meta.미확정_45` 에 명시한다 — 숨기면 읽는 쪽이 확정값으로 읽는다.

## 주어 미상 견적 — 모수를 부풀리지 않는다

`_subject_gap.{json,md}` 는 `subject_type == null` 1,358건을 원인으로 가르고 탐색
범위를 넓힌 **시험 규칙을 실제로 돌려** 회수 가능 건수를 실측한다. 감으로 추정하지
않고, **시험 결과를 `norm_values.json` 에 반영하지도 않는다**(게이트 15).

### 회수 견적의 모수는 321 이지 1,358 이 아니다

| 층 | 수 | 성격 |
|---|---:|---|
| 주어 미상 | 1,358 | |
| 다중값행 계약상 제외 | 1,037 | **회수 대상이 아니다.** spec §주어 판정이 주어를 붙이지 않기로 정한 계약이며 판정 실패가 아니다 |
| **단일값 — 회수 모수** | **321** | 주어를 붙일 수 있는데 못 붙인 것 |

1,358 을 후보로 세면 **4.2배 부풀려진 견적**이 된다. 게이트 14 가 회수 후보에
다중값행·비규범이 섞이지 않았는지만 따로 검사한다.

### 용도지역은 늘지 않는다 — 조례 대조 병목은 여기서 안 풀린다

넓힌 규칙으로 154건을 회수해도 **`용도지역` 은 7 → 7 로 그대로다.** 회수분은 용지 99 ·
블록·획지 55 이고 용도지역은 0 이다. 상한을 보려고 반경 30줄(어떤 방어 가능한 규칙보다
넓다) 안에 용도지역 표기가 있는지 따로 세면 42건이지만, 표본을 열어 보면
`당해 용도지역(준주거지역)에서 허용하는 공장의 범위` 처럼 값의 주어가 아닌 지나가는
언급이다. **이 42 를 회수 견적으로 보고하면 안 된다** — 게이트 16 이 상한과 실제
회수를 분리해 검사한다.

**용지 → 용도지역 매핑은 발급하지 않는다.** 지구마다 다르고 근거가 필요하다
(spec §하지 않는 것). 용지가 468로 늘어도 그것만으로 조례 대조는 열리지 않는다.

### 넓힌 규칙은 반드시 걸린 것을 전수로 눈으로 본다

1차본에서 오탐 3종이 나왔고 전부 육안으로만 잡혔다 — 표 머리 라벨 13건
(`계 획 내 용`·`구분`이 블록 주어로 올라옴), 괄호가 중간에 낀 주어의 절단 9건
(`자족(Ⅰ)시설용지` → `시설용지`), 접속어가 붙은 주어 1건(`다만, 유치원 용지`).
좁히는 과정에서 `단` 을 무조건 벗기다 `단독주택용지` 를 `독주택용지` 로 자른
자기 회귀도 났고, **전후 대조표로만 잡혔다.** 규칙을 좁힐 때도 전후 대조를 낸다.

`규범아님`은 회수 후보에서 **먼저** 뺀다. 순서를 뒤로 두면 `타지표`(비주거용도비율·
연면적 70%)가 회수 견적에 실리고, 실제로 값과 무관한 줄에서 주어를 끌어온 오탐이
1건 있었다(영종하늘도시 1480줄).
