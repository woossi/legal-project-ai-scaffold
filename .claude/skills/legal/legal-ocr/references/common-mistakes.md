# 스캔본 판정

## 실측치

쪽당 실질 글자수(공백 제거)의 하한은 200자이다. 표본은 문서 앞·중간·뒤에서 균등하게 15쪽을
뽑는다. 표지만 비어 있는 경우를 배제하려면 전 구간에서 뽑아야 한다.

| 지구 | 쪽 | OCR 전 쪽당 | OCR 후 쪽당 |
|---|---:|---:|---:|
| 서초구 서초동 1448-1 | 29 | 0.0 (텍스트 레이어 전무) | 744.1 |
| 시흥거모 공공주택지구 | 170 | 9.9 | 780.0 |
| 종전부동산 효행지구 | 29 | 13.4 | 1,599.6 |

## PSM 선택 근거

표본 1쪽으로 세 모드를 비교하였다.

- PSM 3 — 본문 전체가 누락되고 숫자만 남았다
- PSM 6 — 머리말이 누락되고 `공통` 이 `공롱` 으로 오인식되었다
- PSM 4 — 머리말, 본문, 조문번호가 모두 보존되었다. 이 모드를 채택하였다

처리 속도는 쪽당 약 3초이며, 렌더링 1초와 OCR 2초로 나뉜다. 228쪽 문서는 12분 규모이다.
`fold_padding` 을 적용하지 않으면 연속 공백 255자로 게이트에 걸린다. 효행지구에서
확인되었다.

# 읽기 순서 파손은 문자 정확도로 잡지 못한다

2단 조판은 별도 검사가 필요하다. 의심되면 원본을 렌더링해 쪽번호가 한 페이지에 둘 있는지
확인한다. 조문 번호 역전율을 게이트에 넣되 단독으로 판정하지 않는다. 정상 문서도 90분위가
0.009 이다. 효행지구는 표준 게이트를 통과했으나 육안 검증에서 실패하였다.

OCR 문서에만 있는 용어를 격리하면 유령 용어가 잡힌다. 다만 기존 용어의 variant 로 섞인
오인식은 걸리지 않는다.

# 문자 오인식 유형

| 유형 | 실측 | 예 |
|---|---|---|
| 원문자 `①~⑳` | 정상 0건 (전량 소실) | `①`→`(0`·`(7`·`62`, `②`→`@`, `③`→`(8`, `⑤`→`6` |
| 단위 `㎡` | 정상 0건 | `500㎡`→`5007`, `430㎡`→`14307` |
| 백분율 | 10건 | `50%`→`5096`, `500%`→`50096` |
| 조문 접두 | 6건 | `제51조`→`저51조` |
| 로마숫자 | — | `제Ⅱ편`→`제\|\|편`, `제Ⅰ편`→`제Ｌ편` |
| 인용부호 | 심각 | 서초구 여는 `“` 17개 대 닫는 `”` 1개, ASCII `"` 36개 혼입 |
| 일반 한글 | — | 공통→공롱, 획지→겨획, 구간→구긴, 승인권자→승인권재, 공공지원→긍긍지원 |
| 조 표제 `제N조` | 대체로 보존 | 서초구 141 / 시흥거모 403 / 효행지구 222 |

# 오인식 사전 등재

| 표기 | 판정 |
|---|---|
| `자량 진출입불허구간` · `자량출입구` | 오인식이며 정답은 `차량` |
| `가구031000` | 오인식이며 쪽번호·좌표가 혼입되었다. 정의문도 절단되었다 |
| `시항 → 시설` | 오인식이나 제안 대상어가 틀렸다. 정답은 `사항` |
| `권장사항` | 정상. 표제어이다 |
| `없으나 → 없으며` | 정상. 원문이 "강제성은 없으나"이다 |
| `지킬 → 지상` | 정상. 원문이 "지킬 것을 권장하는"이다 |
| `범위는 → 범위를` · `적용에 → 이용에` · `말한 → 접한` | 정상 |

- 문맥까지 확인한 항목만 등재한다
- 어절 선두 매칭(`(?<![가-힣])키`)을 쓰면 조사와 복합어(`시항을`, `획보와`, `자량출입구`)도
  함께 잡히므로 따로 등재할 필요가 없다
- 용어를 흡수할 때는 `ocr_corrected: true`, `ocr_original_term`, `source_quality: "OCR"` 을
  occurrence 와 variant 양쪽에 붙인다

# 변형 규칙을 meta 에 명시한다

1. 연속 공백(개행·탭 포함)을 단일 스페이스로 바꾼다
2. 마크다운 강조를 제거한다. 굵게 표시된 줄이 정의문의 이어지는 문장인 경우가 있어 흡수한다
3. `> [표]` 와 `> [그림]` 마커 줄을 건너뛴다
4. 항·호 앞머리 번호(`- `, `①`, `1.`, `1-1-5-16`, `주1)`)를 제거한다
5. 그 외에는 변형하지 않는다. 꺾쇠·로마숫자·인용부호·괄호는 원문 표기를 그대로 둔다
