# legal-decmap — 실패 유형과 원인

실제로 밟았거나 밟기 직전에 잡은 것만 적는다.

## 1. 이름 충돌로 기존 코퍼스를 덮어쓴다

**증상** — 코드 5 를 받은 뒤 시행지침 본문이 사라지거나 도면으로 바뀐다.

**원인** — `legal-dup/scripts/collect.py` 가 내려받은 뒤 이렇게 개명한다.

```python
readable = ASSET_STEM + os.path.splitext(original)[1].lower()   # ASSET_STEM = "지구단위계획 시행지침"
dst = os.path.join(ddir, readable)
if os.path.abspath(path) != os.path.abspath(dst):
    os.replace(path, dst)
```

파일 종류를 구분하지 않는다. 코드 5 의 확장자가 `.pdf` 면 `dst` 가 이미 있는 본문과 같은
경로가 되고 `os.replace` 가 그것을 지운다. 재개 가드 `prev.get((fileCode, fileRegistNo))` 는
**새 `fileRegistNo` 를 막지 못한다** — 다른 키이므로 건너뛰지 않고 받아서 덮는다.

**대응** — 받기 전에 `savedAs` 를 `fileRegistNo` 별로 유일하게 만든다. 이때 **코드 7 의 현행
이름은 그대로 둔다** — `tables.csv` 의 `출처문서` 가 그 이름을 참조하므로 바꾸면 1층 추출의
표ID 귀속이 깨진다. 새 타입에만 접미를 붙이는 쪽이 안전하다.

## 2. 워크트리에서 실행해 코퍼스가 갈라진다

**증상** — 수집이 성공했다는데 main 의 파일 수가 그대로다.

**원인** — `collect.py` 의 `ROOT` 가 `os.path.dirname(__file__)` 기준이다. **cwd 가 아니라
스크립트가 놓인 저장소가 출력 위치를 정한다.** `.gitignore` 가 `output/legal/시행지침/**` 를
통째로 무시하므로 워크트리에는 원본이 0건이고, 워크트리 사본을 돌리면 그쪽에 새로 받는다.
`meta.json` 도 갈라져 이후 재개 판정이 어긋난다.

**대응** — main 저장소의 절대경로로 실행한다. 코드 수정도 main 쪽 파일에 해야 효과가 있다.

## 3. 축척을 안 보고 전수 수집한다

**증상** — 182지구를 다 받았는데 OCR 이 라벨을 못 읽는다.

**원인** — 병목이 해상도가 아니라 **축척**이다. 1:10,000 도면은 같은 지면에 3배 많은 획지를
담아 라벨이 항상 경계선·분할선과 맞닿는다. 이 겹침은 해상도를 올리거나 개별 라벨을 4배
확대해 오려내도 풀리지 않는다.

실측이 순위 역전을 보였다 — DPI 최고 지구(492~722)가 겹침률 최저(2%)였고, DPI 최저
지구(356)가 수동 크롭 후 더 높았다.

**대응** — 표본 5~8지구로 축척 분포를 먼저 재고 값하는지 판정한다.

## 4. 목차를 도면으로 센다

**증상** — 결정도를 가진 지구 수가 실제보다 많다.

**원인** — 시행지침 PDF 의 목차에 `가구및획지의규모와조성에관한도시관리계획결정(변경)도` 가
**항목으로** 실린다. 제목 정규식이 그것을 도면 쪽으로 잡는다. 실제로 곤지암(`41610DA2016001`)
p2 가 그렇게 잡혔고 33쪽 전수에 결정도가 없었다.

**표지** — 그 목차에서 결정도 항목만 쪽번호가 없다. 다른 절 항목에는 있다.

**대응** — 제목만 보지 말고 그 쪽에 이미지나 벡터 drawing 이 있는지 함께 본다.

## 5. 벡터를 전제한 필터가 래스터를 통째로 가린다

**증상** — 단일 pdf 에 결정도가 없다고 판정했는데 실제로는 있다.

**원인** — 도면 쪽 판별을 `벡터 drawing ≥ N` 으로 잡으면 **래스터로 실린 결정도가 안
걸린다.** 강일(`11740DA2010001`) p39 가 정확히
`라. 가구 및 획지의 규모와 조성에 관한 도시관리계획 결정(변경)도` 인데 텍스트는 제목 12단어
뿐이고 지도는 `4200×245` jpeg 11장 타일이었다.

**대응** — 제목 어휘 · 이미지 보유 · 낮은 단어 수를 함께 쓴다. 벡터 여부는 판별 조건이
아니라 관측 결과로 적는다.

## 6. 첨부가 있다는 기록과 받았다는 기록을 혼동한다

`meta.json` 의 `districts[].attachments` 는 **서버에 존재한다**는 목록이고
`districts[].downloaded` 가 **받았다**는 목록이다. 둘을 같은 것으로 읽으면 190지구가 도면을
다 가진 것처럼 보인다. 실제로는 코드 7 만 190건이고 나머지 넷은 0건이다.
