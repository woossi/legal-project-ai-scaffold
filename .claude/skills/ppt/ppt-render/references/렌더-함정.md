# PPT 렌더 함정

- 모듈 import 시 `Presentation()`을 만들거나 파일을 저장하지 않는다. 모든 렌더는 `build()` 안에서 실행한다.
- PowerPoint 텍스트 상자의 기본 마진은 좌표 실측을 바꾼다. 새 텍스트 상자는 네 마진을 명시한다.
- 한글 글꼴 폴백은 조용히 처리하지 않는다. 요청 글꼴과 실제 글꼴을 빌드 리포트에 기록한다.
- LibreOffice PDF 변환은 PowerPoint와 줄바꿈이 다를 수 있다. 미리보기만으로 네이티브 PowerPoint 결과를 확정하지 않는다.
- 시각자산은 원본 비율을 보존해 맞춘다. 가로·세로를 동시에 강제해 늘이지 않는다.
- 렌더러는 넘치는 텍스트를 자르지 않는다. 스펙 소유자인 ppt-writer에게 반려한다.
