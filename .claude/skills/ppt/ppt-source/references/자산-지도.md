# PPT 입력 자산 지도

이 문서는 경로와 용도만 고정한다. 건수와 파일 크기는 `scripts/measure.py`로 실행 시점에 다시 센다.

| 계통 | 우선 경로 | 발표 용도 | 확인할 한계 |
|---|---|---|---|
| 수집 | `output/legal/시행지침/meta.json` | 지역·사업단계·원본 보유 범위 | 수집 지구와 분석 문서의 모수 구분 |
| 표 | `output/legal/table/norm_values.json` | 건폐율·용적률 등 규범값 | 파싱 실패·격리 상태 |
| 대조 | `output/legal/contrast/{norms,pairs}.json` | 지구 간 차이 | 생성시점·필터·중복 조건 |
| 법령 | `output/legal/statute/guideline_statute_master.json` | 인용 법령 범위 | 미수집·미검증 조문 |
| 용어 | `output/legal/word/terms.json` | 용어 빈도·정의 변이 | OCR·저신뢰 포함 여부 |
| 참조 | `output/legal/xref/xref_index.json` | 조문·법령 연결망 | 고립·미해소 참조 |
| 구조 | `output/legal/analysis/시행지침_목차구조_전수조사.csv` | 목차 유형 비교 | 행 모수와 예외 행 |
| KB | `output/kb/{ontology,graph,reports}/**` | 지식구조와 게이트 | 파일럿 표본의 일반화 금지 |
| 시각화 | `output/viz/**` | 기존 그림·웹 집계 | 집계 기준시점과 원천 해시 |

`dashboard.json`과 세부 산출물의 값이 다르면 하나를 선택해 fact를 발급한다. 두 값을 평균하거나 최신값으로 추정하지 않는다.
