# PPT 문체 판정

## 제목

제목은 덱 또는 슬라이드의 역할을 명명한다.

| 판정 | 예시 | 기준 |
|---|---|---|
| 통과 | `Task 1 — 시행지침 수집` | 역할명과 대상 명사구 |
| 통과 | `검증 게이트 구성` | 명사구 종결 |
| 실패 | `분석 결과 문제가 있었다` | 서술형 종결 |
| 실패 | `분석 결과 문제가 있었음` | 명사화된 완결절 |
| 실패 | `왜 필요한가`·`왜 필요한가?` | 문장부호와 무관한 의문형 제목 |
| 실패 | `자동검증은 누락을 놓쳤다` | 주어와 서술어가 있는 완전한 문장 |

## 본문

본문은 `~함`, `~됨`, `~임`, `~음` 또는 명사구로 닫는다.

- 통과: `시행지침 189건 분석함`
- 통과: `분모 165 기준`
- 실패 후보: `시행지침을 분석했다`

형태소 분석 없이 종결 패턴만 검사하므로 애매한 문장은 ppt-verifier가 사람이 읽고 판단한다.
