# PPT 검증 사각지대

- LibreOffice 미리보기는 PowerPoint 또는 Keynote의 네이티브 렌더 결과와 다를 수 있다.
- 종결 패턴 검사는 한국어 형태소와 문장 성분을 완전하게 판정하지 못한다.
- 길이 기반 오버플로 검사는 실제 글꼴 메트릭과 도형 겹침을 완전하게 판정하지 못한다.
- fact_refs의 존재와 해시는 근거 해석의 타당성을 보장하지 않는다. 원천 대조 반박검증이 별도로 필요하다.
- 시각자료의 색상 오도, 지도 범례, 표의 잘못된 집계는 PPTX 구조 검사만으로 판정하지 못한다.

`03_qa.json`의 `blind_spots[]`에는 이번 실행에서 실제로 남은 사각지대를 기록한다.
