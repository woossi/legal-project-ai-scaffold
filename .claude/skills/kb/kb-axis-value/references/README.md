# 색인

축별로 갈라 둔다. **전부 읽지 말고 다루는 축의 것만 읽는다** — kb-norm 의
`common-mistakes.md` 가 327줄 단일 파일이라 매번 전부 읽히는 것을 피하려는 구조다.

| 파일 | 다루는 것 |
|---|---|
| `공통.md` | 축과 무관하게 골격에서 데인 것 — 근거항 판정·별표 확인·조건 가르기 |
| `표기변형.md` | 원문 표기에서 데인 것 — 단위·조사·마크업·세분 주어 |
| `검사기-함정.md` | **검사기가 틀린 것.** 주석보다 느슨한 코드·소멸만 보는 검증·종료코드 판정 |

축별 파일은 그 축에서 실제로 유입된 것이 생길 때 만든다. 없는 축의 빈 파일을 미리
두지 않는다 — 빈 파일은 "함정이 없다"와 "아직 안 봤다"를 구분하지 못한다.

실측 회귀는 `case/t_engine.py` 에 있다. 여기 적힌 것은 전부 그 파일에 테스트가 있다.
