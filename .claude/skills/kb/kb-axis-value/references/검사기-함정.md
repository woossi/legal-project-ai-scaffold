# 검사기에서 유입된 것

산출물이 아니라 **검사기**가 틀린 유형. 검사기가 틀리면 결함이 통과하고,
통과했다는 사실 때문에 아무도 다시 보지 않는다.

## 1. 주석이 맞고 코드가 느슨하다

2026-08-14 실측. `invariant_check.py` 의 `target_ok` 주석은

> 대지면적을 '면적' 으로 축약한 자리. '…인 대지' 로 이어지면 대지면적이다

라고 적혀 있었는데 코드는

```python
return tgt == "대지면적" and so.startswith("면적")
```

뿐이라 **'인 대지' 확인이 없었다.** 주어원문이 '면적' 으로 시작하고 앞 글자가
'연' 이 아니기만 하면 무조건 통과한다. 공개공지의 `바닥면적` 이 정확히 그
자리다 — 앞 글자가 '바닥' 이라 '연' 검사를 빠져나간다. 검증자가 12건에
심었을 때 **전건 미검출**이었다(M8b).

**주석이 조건을 셋 말하면 코드에 셋이 다 있는지 본다.** 주석은 의도이고 코드가
실제다. 오늘 이 형태가 반복됐다 — 조경에서 '연면적' 앞 글자를 흘린 것도
"낱말 뒤부터 다시 찾는다" 는 의도와 실제 동작이 어긋난 것이었다.

## 2. 소멸 검사만으로는 거짓 양성을 못 잡는다

파서를 넓히면 **사라지는 것이 아니라 없던 것이 생긴다.** 의미 키 대조로
'소멸 0' 을 확인하고 거짓 양성 0 이라고 보고했는데 실제로는 23건이었다.
값이 원문에 있고 올바른 명제도 따로 있어 환각 검사도 통과했다.

**파서를 넓히면 `case/new_statement_audit.py` 로 신규 전건을 원문 대조한다.**

## 3. 종료코드로 변이 시험을 판정하면 거짓 통과한다

106건을 심고 56건만 잡혀도 종료코드는 1 이라 '잡힘' 으로 찍힌다. 미검출 50건을
못 본다. `case/mutation_test.py` 는 **심은 수와 잡힌 수를 세고 미검출률을 낸다.**

## 4. 검사기를 완화할 때 변이 시험을 다시 안 돌리면 조용히 통과하기 시작한다

값기준 검사를 "조문 어디에나 있으면 통과" 로 넓혔더니 주어절의 '연면적' 이
근거로 오인돼 M5 가 빠져나갔다. 튜닝 중 두 번 그랬고 둘 다 mutation 으로만
잡혔다. **검사기를 고칠 때마다 mutation_test 를 돌린다.**

## qa-verifier 가 검사할 것

만든 쪽이 자기 산출물을 검증하면 자기 일관성만 확인하게 된다. 검사 항목의 정본은
`contract/axis_value.json` 의 `qa검사항목` 이며 요지는 다음이다.

| 검사 | 표적 |
|---|---|
| 축별 커버리지 하한 | 추출단위가 있는 축의 명제가 0건이면 파서 결함을 의심한다 |
| 값없음사유의 검증 가능성 | 근거 발췌 없는 `별표결손_corpus` 는 사람의 판단이지 확인이 아니다 |
| 분모 3종 | 셋이 각각 다른 수이며 정의가 계약과 맞는지 |
| 위임사슬 대조 | 모든 명제의 근거 조문이 `delegation.ttl` 의 delegates 대상인지 독립 재계산 |
| 축간 오염 | 축별 TTL 에 다른 축의 값이 섞이지 않았는지. 부설주차장의 장애인주차 4퍼센트가 대표 함정 |
| 멱등성 | 두 번 실행해 축별 파일 diff 가 비는지 |

`delegation.ttl` 이 없으면 위임사슬 대조는 **미검사**다 — 실패가 아니다. 없다고 명제를
전부 격리하면 축이 통째로 0건이 되어 별표결손 같은 진짜 사유가 묻힌다.
