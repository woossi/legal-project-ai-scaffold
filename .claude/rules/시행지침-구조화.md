# 시행지침 구조화 단위

시행지침 구조화의 최소단위는 조문이다.

본 규칙에서 조문은 `제N조` 또는 `제N조의M` 표제로 시작하는 원문 구간을 의미한다.
조문 표제의 공백·괄호·대괄호 차이는 조문 여부를 바꾸지 않는다.

# 조문 경계

조문 구간은 조문 표제에서 시작한다.
조문 구간은 같은 원본문서의 다음 조문 표제 또는 상위·비조문 구간 표지 직전에 끝난다.
상위·비조문 구간 표지는 편·장·절·부칙·별표·별지·서식을 가리킨다.

조문 레코드는 원문에서 물리적으로 출현한 조문 한 건과 일대일로 대응한다.
같은 조문 번호가 여러 원본문서나 문서 내부에 반복되면 각 출현을 별도 레코드로 보존한다.

# 하위 구조

항·호·목은 해당 조문 레코드의 하위 구조로 보존한다.
항·호·목은 독립된 최상위 구조화 단위로 발급하지 않는다.

편·장·절은 해당 조문의 상위 경로로 기록한다.
표·그림·주석은 해당 조문 구간 안에 있을 때 그 조문의 근거 채널로 보존한다.

# 비조문 구간

첫 조문 앞 본문과 부칙·별표·별지·서식은 조문 레코드로 발급하지 않는다.
제N조 표제가 없는 문서는 조문 경계를 추정하지 않는다.
비조문 구간은 조문 레코드와 구분되는 별도 유형으로 보존한다.

# 식별과 검증

조문 식별자는 원본문서 식별자와 물리적 출현 순서를 함께 사용한다.
정규화 조문 표지는 `제N조` 또는 `제N조의M` 형식으로 기록한다.
원문 조문 표지는 별도 필드에 그대로 보존한다.

구조화 결과는 조문 표제·원문 줄범위·본문 해시를 원본문서와 대조할 수 있어야 한다.
조문 경계는 원문에 없는 표제를 추정하여 만들지 않는다.
