# 현재 상태 — 재설계 중

**2026-08-25에 온톨로지를 3계층으로 재설계하기로 했다. 이전 구조는 폐기됐고 `output/kb/` 산출물은 삭제됐다.**

이 문서는 재설계가 끝나기 전까지 **무엇이 폐기됐고 무엇이 살아있는 사실인지**만 담는다. 새 구조는 여기에 미리 적지 않는다.

# 3계층 체계

존재론 층은 셋이다.

| 층 | 대상 |
|---|---|
| **사업** | 개별 사업지구. 190건이 여기 속한다 |
| **계획** | 지구단위계획. **사업의 부분이 아니라 별도의 존재론 층이다** |
| **공간** | 용도지역·구역·가구·획지. 최소 단위는 획지다 |

법령은 존재론 층이 아니다. 사업·계획·공간이 존재하는 대상이고, 법령은 그것들이 왜 그렇게 성립하는지를 대는 **근거**다.

결과(행정문서·공간 활용 실태)는 데이터가 미정이라 이번 설계 대상에서 제외한다.

## 공간 층

- 획지 데이터를 가진 지구는 **38/190(20.0%)**. CSV가 다루는 지구가 136이고 그중 38이다. **이 38은 하한이다** — CSV에 없는 54지구 미조사, `미상` 4,908행 중 실제 획지 비중 미조사

- 표기 규약이 지구마다 다르고 한 지구 안에서도 혼용된다. 식별자가 아닌 문자열 10건이 섞여 있다(`-`, `계획연면적`, `합` 등)

## 근거(법령)

- 위임 사슬 원천은 `output/legal/` 조문 corpus. 이전 그래프(`delegation.ttl`)는 삭제됐으나 실측은 재현 가능하다 — 간선 2,195건이 시행령→조례 1,295 · 법률→조례 885 · 법률→시행령 15였고 **훈령 관여는 0건**이었다
- 뿌리 미도달 857건(39.0%). 원인은 법→영 다리가 15건뿐이라는 것과, **IRI 표기 분열**(corpus `official_name` 공백 `%20` 인코딩 대 `law_roots.json` 이름)이 겹쳐 있다. 두 원인의 비중은 미판정
- 훈령(수립지침) 수권 조문은 **법 제49조제2항 → 영 제42조의3제2항**이다. 법 제52조제1항이 아니다
- **시행지침이 규범을 창설한다.** 특별계획구역(수립지침 3-15)은 법·영에 출현 0건인데 시행지침 50/189 지구가 쓴다. 고덕 시행지침의 `투시형`은 법령 코퍼스 365종 중 국토계획법 계통에 없고 `기단부`·`실외기`는 365종 전체에 0건이다. "관련법령과 다를 경우 규제내용이 강화된 것을 따른다"가 189개 중 124개(65.6%)에 있다

# 재현되지 않는 기록

아래는 근거를 찾지 못했다. 인용 전에 재확인이 필요하다.

- **획지 발급 모수 745** — 재현 실패. 751은 `(지구, 적용대상원문)` distinct로 재현되지만 745는 산출 근거가 ADR 본문에도 스크립트에도 없다. 실측 비식별자는 10건이라 751−10=741이다
- **ADR 0015의 "25,269행"** — 물리 줄 수를 레코드 수로 센 값. 실제 레코드는 20,327
- **`NormStatement` 1,086** — 단일 파일값이다. 서브파일 4종 467건과 교집합이 0이므로 층 전체는 1,553이었다

# 규율 (재설계에서도 유지)

- det(근거 사슬 — 추론 대상) / prob(판정 — 추론 금지) 분리
- 근거 채널은 본문·표·그림 3종. 본문만 읽고 "규정 없음"으로 판정하지 않는다
- 미구현 구조를 구현된 트리플처럼 기록하지 않는다. 근거 요건을 못 채우면 간선을 만들지 않고 리포트에 격리한다
- 근거가 약한 값은 격리가 아니라 저신뢰 플래그로 발급한다. 격리와 플래그를 혼동하지 않는다
- 부분문자열 정규식으로 표제를 개념에 직결하지 않는다. 매핑마다 근거를 기록한다
- 관측값을 확정값으로 승격하지 않는다
- **문언 일치를 조문동등성으로 승격하지 않는다.** 시행지침 조문동등성은 문언후보(`exact`·`similar`) → 정의환경 대응(`aligned`·`different`·`unknown`) → `(Σ, Q, C, t)` 상대적 규범동등성 주장(`supported`·`refuted`·`unknown`)의 세 층으로 나눠 판정한다. 정의 진술은 용어 × 시행지침 판본 × 출처 조문 × 정의문 × 외부 참조 × 기준시점의 다항 관계이며 용어의 전역 속성으로 접지 않는다. 개별 시행지침은 내부 정의와 외부 법령·관습적 의미를 함께 쓰는 열린 정의환경이다. 조문·용어·시행지침 판본 사이에 `owl:sameAs`를 발급하지 않는다. 현재 E5 임베딩 군집은 정의환경을 쓰지 않은 문언후보이므로 자동 정규화·스키마 자동 적용의 근거로 승격하지 않는다. 근거는 조문동등성 ADR — 브랜치 `docs/definition-aware-normalization-adr` 커밋 `76c1aa1`, 상태 설계만. 그 브랜치의 번호 0051은 main 미커밋 3D 엔진 ADR 초안과 겹치므로 번호가 아니라 브랜치·커밋으로 참조한다
- **소수 사례로 세운 분류는 확장하면 깨진다.** 의제를 3종으로 시작했다가 6개 법으로 확장하니 4종이 필요했고, 규범형식 3분류는 354항 전건 검사에서 5종이 더 나왔다. 분류를 세울 때 모수를 밝히고 확장 시 재검토한다
