# Canonical Rule Pointer

시행지침 구조화 작업을 시작하기 전에 `.claude/rules/시행지침-구조화.md`를 읽는다.

시행지침 구조화의 최소단위는 `제N조` 또는 `제N조의M` 형식의 조문이다.
항·호·목은 해당 조문의 하위 구조로 보존한다.
편·장·절은 해당 조문의 상위 경로로 기록한다.
비조문 구간은 조문 레코드와 구분되는 별도 유형으로 보존한다.

이 파일은 Codex 라우팅 포인터다.
구조화 단위와 경계의 정본은 `.claude/rules/시행지침-구조화.md`다.
