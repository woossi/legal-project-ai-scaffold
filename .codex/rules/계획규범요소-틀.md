# Canonical Rule Pointer

Before any work involving 온톨로지 스키마, 클래스 계통, 계획항목(L1), 규범형식·값 도메인,
or 스키마 설계, read the canonical rule at `.claude/rules/계획규범요소-틀.md`.

핵심 넷을 건너뛰지 마라:

- **온톨로지는 재설계 중이다.** 2026-08-25에 3계층(사업·계획·공간)으로 다시 짜기로 했고
  `output/kb/` 산출물은 전부 삭제됐다. 이전 구조를 인용하지 말 것.
- **폐기된 것** — 9계통 클래스 스키마, 5축 필요요건 성립 구조,
  `DistrictUnitPlan → PlanState → PlanningRule` 3단, `PlanState` 발급 정책.
  이 이름들이 나오면 낡은 문서다.
- **법령은 존재론 층이 아니다.** 사업·계획·공간이 존재하는 대상이고 법령은 근거다.
  계획은 사업의 부분이 아니라 별도 층이다.
- **폐기된 것은 구조이지 실측이 아니다.** 지구 190건·규칙 20,327 레코드·획지 커버리지
  38/190·계획항목 26 같은 실측은 원자료에서 재현 가능하며 재설계의 입력이다.
  다만 재현되지 않는 기록 셋(획지 745, ADR 25,269행, NormStatement 1,086)은
  인용 전에 재확인할 것.

법령 근거(공간 층위·지정 근거·의제·절차 단계·제52조 내용)는
`.claude/rules/지구단위계획-법정구조.md`가 정본이다.

Trigger pointer only.
